# TradeEnglish AI · AI外贸英语教练

可运行的 Next.js / TypeScript 学习应用。第一版为无需注册的本机演示模式，默认：初中基础、en-US、综合外贸、听力与口语、0.75倍、双语解释、60分钟。

## 启动

安装 Node.js 20.9+（含 npm），在此目录执行：

```sh
npm install
npm run dev
```

打开 http://localhost:3000 。生产运行：`npm run build` 后 `npm start`。也支持 pnpm。

当前 Codex 环境提供 Node 和 pnpm、未提供 npm 命令，可使用根目录 `start.ps1` 启动。常规 Node 安装直接使用上述命令即可。

## 功能

- 10个可切换页面，响应式白色/浅蓝色学习界面。
- 7天真实课程：每天6词（共42词）、音标、例句、业务场景、4句中英对话、知识解释、听力选择题、听写。
- 每日10+15+20+10+5分钟任务；手动完成后累计计划时长，不假装是真实计时。不同学习日的完成记录隔离；重复完成不会重复累计。
- localStorage持久化偏好、单词收藏/掌握、任务、聊天、错题和个人句库。个人设置修改即时保存，可导出JSON备份。
- 浏览器speechSynthesis发音、逐句播放、相对语速控制；优先选en-US音色，缺失时回退到英语音色。实际效果取决于操作系统。语音播放错误有提示。
- 浏览器SpeechRecognition/webkitSpeechRecognition麦克风输入，结果先放到输入框供确认；兼容性、权限和错误提示完整。推荐Chrome/Edge；麦克风需localhost或HTTPS，部分浏览器识别依赖外部网络。
- 规则演示陪练与WhatsApp模拟；帮助按钮、结束总结。规则演示不会理解任意自由表达或进行语法评分，界面明确标注。
- 服务端OpenAI Responses API文字陪练和任意业务消息解析。默认使用 `gpt-4.1-mini`，可用环境变量更改为账户可访问的模型。AI提示遵循个人偏好，并根据求助情况与表现调整；静态7天课程固定。
- 业务消息预置示例可无密钥准确解析；其他任意消息需要AI密钥。不伪造翻译结果。
- 错题支持间隔复习（1、2、4、8、14天），听不懂句子和错误听写进入错题本。口语AI总结仅显示在聊天中；需复习的口语句子通过“我没听懂”等帮助按钮加入。
- 90天分阶段目标和考核标准；第8–90天明确为待扩展。

## 接入真实AI

复制 `.env.example` 到 `.env.local`：

```env
OPENAI_API_KEY=你的服务端密钥
OPENAI_MODEL=gpt-4.1-mini
```

重启开发服务，在陪练/WhatsApp页面右上角切换“真实AI”。业务消息解析自动调用服务端，缺少密钥时只提供预置示例。AI失败明确报错，不会静默伪装成功。API密钥只在服务端读取，禁止以 `NEXT_PUBLIC_` 暴露。没有密钥也能使用全部固定课程、浏览器发音、规则对话、复习和本地记录。

## 隐私与边界

第一版未接入Supabase、登录与跨设备同步。数据按浏览器存储，同浏览器使用者可访问，请勿将其当作账户级隔离。更换浏览器或清除浏览器数据会丢失本地记录；建议导出备份。真实AI模式会将最近对话/粘贴消息发送至OpenAI，使用 `store:false`；不能将此视为服务商零保留保证。浏览器语音识别也可能使用浏览器厂商云服务。

本服务面向本机开发；API路由做了消息长度/类型校验及超时，但尚未实现生产级登录鉴权、每用户限流、计费额度与审计。部署到公网前必须完成这些控制，避免他人滥用你的API额度。不要把含真实客户隐私的资料放入公开示例。

未实现：专业发音评分、OpenAI Realtime实时对话、PDF/Word/Excel解析、云账户同步。每日目标可修改，但固定60分钟示范课程不会自动重排；行业/英语水平/学习重点用于真实AI提示，不会重写固定课程。

## 验证
